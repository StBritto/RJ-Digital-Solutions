# Splytto Android v1.2

Splytto is an expense-splitting Android app concept combining splitting, AI-assisted receipt scanning, UPI settlement, guest sharing and social trip stories.

## Key features
- First-run user profile
- Original split categories plus highlighted AI Bill Scanner
- Editable item assignment after receipt scan
- Expense photos, places and notes
- Splytto Stories and social sharing
- Smart guest/share link concept
- Google Pay / PhonePe / UPI launch flow
- Settlement success/pending emotions

## Build
Use Android Studio or Gradle with Android SDK 36. For a test APK run `gradle assembleDebug`. For Play Store generate a signed AAB using a permanent upload key.
